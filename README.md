# plsDontProc downloads

Official Windows installers for **plsDontProc** and **plsDontProc Premium**.

Download published installers from [Releases](https://github.com/Extarzan/plsdontproc-releases/releases).
The first public installer has not been published yet.

Installed versions with the updater check for new releases automatically and show an in-app notification.
Choose **Update** to download, then **Restart and install** when your current search has finished.
Your account and saved settings stay on your computer.

This repository contains distribution assets and signed update metadata only. It does not contain application source code.
Standard and Premium updates use separate signed channels.
